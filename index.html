Accounts

Each account's balance is stored where net worth already reads it — a bank account's in Cash, an offset's on its loan, a card's or loan's in Debts — so updating it here updates everything. A credit card also has a statement cycle (set its start day, e.g. 15 for a 15th–14th cycle) and an optional limit, which only feeds "available" and never counts as owed.

How spending is grouped for the charts — a category should cover several budget lines, not restate one.

Categories

Set a category on each budget line (Cash flow → Budget) and the charts there show what you plan and actually spend per category. Categories work best coarse — one "Car" covering rego, insurance, fuel and servicing says more than four categories that each match a single line. Renaming one here updates every line using it; deleting one leaves those lines uncategorised rather than removing them.

What the bank import has learned: which words in a statement line file it under which budget line. Fix a wrong one, or add one before an import.

Import rules

A rule matches whole words anywhere in a statement line, ignoring case and punctuation; when two match, the longer one wins, so "fern cafe north" beats "fern cafe". Confirming a row in an import updates its rule.

Your year

Which twelve months this app treats as "a year" — the same choice as "Year runs" in the period menu beside the page title. Used by the year-to-date spending view, the transactions export, the share price "YTD" timeframe, and the tax estimate on the Tax page. Long-term projection

net worth over time

Projects each scenario's net worth forward: your home equity grows with the property and shrinks with the loan paydown, while your surplus savings (and existing portfolio) compound as investments. A scenario with its own "invest instead of buying" leg (Scenarios tab) compounds that money at its own growth rate instead. Living costs and housing costs inflate each year and your income grows at its own rate; a mortgage repayment is the one thing that stays fixed in nominal terms, as it is in reality. Any row given an "Ends" date stops counting from then on. All assumptions below are yours to set — treat the result as a "what if," not a forecast.
