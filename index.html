Accounts

A debit/savings account has no due date — spending there just draws it down. A credit card has a statement cycle instead, so each transaction hits separately; set its cycle's start day (e.g. 15 for a 15th–14th cycle) so "Actual vs. planned" on the Expenses tab can total up the current bill.

How spending is grouped for the charts — a category should cover several budget lines, not restate one.

Categories

Set a category on each budget line (Expenses → Budget) and the charts there show what you plan and actually spend per category. Categories work best coarse — one "Car" covering rego, insurance, fuel and servicing says more than four categories that each match a single line. Renaming one here updates every line using it; deleting one leaves those lines uncategorised rather than removing them.

Long-term projection

net worth over time

Projects each scenario's net worth forward: your home equity grows with the property and shrinks with the loan paydown, while your surplus savings (and existing portfolio) compound as investments. A scenario with its own "invest instead of buying" leg (Scenarios tab) compounds that money at its own growth rate instead. Shared living costs and non-loan housing costs (insurance, rates, water, maintenance) inflate each year; loan repayments stay fixed in nominal terms, as they are in reality. All assumptions below are yours to set — treat the result as a "what if," not a forecast.
